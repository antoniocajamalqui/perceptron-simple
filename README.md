
# Perceptrón Simple - UCV

## Descripción
Proyecto que implementa un perceptrón simple
para realizar la aprobación preliminar de créditos.

## Objetivo
Comprender el funcionamiento de una neurona
artificial mediante Python.

## Entradas
- Ingreso mensual.
- Historial crediticio.

## Resultados
- 1: Crédito aprobado.
- 0: Crédito rechazado.

## Tecnologías
- Python
- Git
- GitHub
- Pytest
- GitHub Actions

## Ejecución
Ejecutar el programa:

python main.py

## Pruebas
Ejecutar:

pytest -v
